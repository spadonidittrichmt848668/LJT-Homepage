# LJT-Homepage

Personal academic homepage of **Junteng Liu**, first-year PhD candidate at the HKUST NLP Group, supervised by Professor Junxian He.

Built with [Jekyll](https://jekyllrb.com) and the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template (forked from `academicpages/academicpages.github.io`).

## Site content

* `_pages/about.md` — the about page (homepage): personal details, education, research experience, research interests and skills, publications, honors and awards, contact information
* `_pages/publications.html` — the publications page, generated from the `_publications/` collection
* `_publications/` — one Markdown file per publication
* `_config.yml` — site and author (sidebar) settings
* `_data/navigation.yml` — header navigation (About, Publications)
